# 검토 보고서 — 수포자 스킬(교수법 7원칙) + 페르소나 감사

- 대상: `index.html`, `ch1_why.html` ~ `ch6_practice.html` (7쪽, 중챕터 25개)
- 독자 가정: 혼합형(수포자형 + 통포자형). 비전공 독자가 기준이며, 전문가는 펼침·코드 상자로 따라오게 함
- 검토 방식: 페이지를 헤드리스 브라우저로 열어 모든 버튼·슬라이더를 눌러 보고(콘솔 오류 0, 글꼴·대체 표지 로딩 제외), 본문 수치는 분석용 CSV로 코드를 다시 돌려 대조함
- 반영: 검토에서 찾은 과제 중 1~7순위를 같은 날 반영했고, 아래 표의 "반영 후" 점수는 반영본 기준

### 문제 문장 → 고친 문장

| 위치 | 전 | 후 |
|---|---|---|
| 5-2 수식 | λ는 0~1 사이 난수 | λ(람다)는 0~1 사이에서 무작위로 고른 수 |
| 3-3 "왜 첫 질문이 장해등급일까" | "장해가 있는가(1~14급) 없는가(15)" | "1~14급 쪽인가, 장해가 없는 쪽으로 보이는 코드 15인가" (코드 뜻을 단정하지 않음) |
| 2-3 한계 | 범주형 코드 번호의 부호 문제만 언급 | + 만족도·소득·건강처럼 **같은 해에 잰 변수**는 이용의 결과일 수 있어 실제 쓰임보다 성적이 좋게 나올 수 있음 |
| 6-5 로드맵 2 | 지난 해 응답을 변수로 더함 | + 이용 뒤에 바뀔 수 있는 같은 해 변수는 빼고 "이용 전에 알 수 있는 정보"만으로 맞혀 봄 |

## 2. 페르소나 감사

제10회 산재보험패널 학술대회 포스터 발표(2024-05-17)를 연구실 해설 7쪽으로 옮겼다. 1~4장은 발표 내용(목적·데이터·세 모델·혼동행렬)을, 5장은 발표가 한계로 남긴 불균형 문제를 같은 데이터로 직접 검증한 결과를, 6장은 재현 코드 실습과 현장 적용을 다룬다. 핵심 메시지는 "정확도 84%가 찍기 점수일 수 있으니 성적표를 네 칸으로 읽어라"이다.

### 5. 정리
입문 쪽(A·B·D)은 캐릭터 대화와 손계산 덕분에 따라오기 쉽다고 봤지만, 기호 하나·서비스 설명 하나·실행할 데이터가 없는 곳에서 멈췄다. 전문가 쪽(C·F)은 재현과 교차검증의 정직함을 높이 샀고, 가장 무거운 지적은 "같은 해에 잰 변수가 결과를 미리 품고 있을 수 있다"는 시점 문제였다. 교수자(E)는 구성의 고르기를 봤다. 비용 대비 효과가 가장 큰 것은 1(시점 한계), 3(3장 AI 판단 코너), 7(가짜 데이터)이었고 모두 반영했다. 남은 과제 중에서는 9(원-핫 인코딩 실측)가 다음 개정에서 해 볼 만하다.
