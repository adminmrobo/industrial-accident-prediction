# 산업재해 패널 데이터를 활용한 머신러닝 모델 — 모델 구성 및 성능 평가 방법 제안

> 재활 서비스 예측 연구실 · 제10회 산재보험패널 학술대회 포스터 발표 해설 (2024-05-17, 대한상공회의소 중회의실 A·B, 근로복지공단 근로복지연구원 주최)

산재보험패널 2,728명의 데이터로 "누가 재활 서비스를 이용할까"를 맞히는 머신러닝 모델 세 가지(KNN · 로지스틱 회귀 · 의사결정나무)를 만들고, 그 성적표를 바르게 읽는 법과 불균형 데이터 보완을 비전공 독자용 인터랙티브 해설 6장(중챕터 25개)으로 풀었습니다. 박사 · 조수 하루 · 초파리 연구원 · 주판봇이 진행하고, 인턴 시아 · 모아와 미공개 식구 X1~X3(가상 사례 카드)이 함께 나옵니다.

## 숫자 표시 원칙

발표 표·그림에서 옮긴 값은 "발표 자료 값", 같은 분석용 파일로 코드를 다시 돌린 값은 "코드 재현", 이 페이지가 설명을 위해 만든 값은 "설명용"으로 따로 표시했습니다.

- 같은 나누기(`random_state=42`)에서 KNN 아홉 개 지표는 발표 값과 소수 둘째 자리까지 같고, 상관관계 표도 같습니다. 로지스틱 회귀(수렴 경고)와 의사결정나무(무작위 갈림)는 한두 명 차이가 납니다.
- 발표 27쪽 그림의 직업재활 14.4% · 사회재활 23.4%는 분석용 파일로 센 15.9% · 17.9%와 다릅니다. 해설은 파일 값을 쓰고 차이를 2-2에 적었습니다.
- 발표 표의 "변수 65개"는 파일의 입력 변수 68개(ID·타깃 제외)와 다릅니다. 장해·경제활동 유형처럼 쪼갠 변수를 하나로 센 것으로 보입니다.
- 5장은 발표에 없는, 이 해설이 같은 데이터로 직접 해 본 검증입니다(표준화·가중치·SMOTE·교차검증).
